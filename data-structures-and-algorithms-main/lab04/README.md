## Описание

Лабораторная работа посвящена исследованию алгоритмов сортировки с гарантированной оценкой $\mathcal{O}(n \log n)$ и линейных некомпараторных сортировок, а также их экспериментальному сравнению с QuickSort (из ЛР 3) и встроенной сортировкой Python `sorted()`:

- `merge_sort` — сортировка слиянием с гарантией $\mathcal{O}(n \log n)$ во всех случаях. Реализовано стабильное слияние с условием `<=`, выделение памяти $\mathcal{O}(n)$.
- `counting_sort` — устойчивая сортировка подсчётом с префиксными суммами и расстановкой элементов с конца массива. Сложность $\mathcal{O}(n + k)$, память $\mathcal{O}(n + k)$. Ограничение диапазона ключей: эффективна при $k = \mathcal{O}(n)$.
- `radix_sort_lsd` — поразрядная сортировка LSD по десятичным разрядам на базе устойчивого поразрядного подсчёта. Сложность $\mathcal{O}(d \cdot (n + b))$, где $d$ — количество разрядов, $b = 10$.
- `heap_sort` — пирамидальная сортировка in-place через просейку вниз (`sift_down`). Построение max-кучи снизу вверх за $\mathcal{O}(n)$, суммарное время $\mathcal{O}(n \log n)$, дополнительная память $\mathcal{O}(1)$. Нестабильная.
- `quick_sort` — перенесен из ЛР 3 со случайным выбором pivot и хвостовой оптимизацией глубины стека.
- `sorted()` — встроенный Timsort в качестве эталона.
