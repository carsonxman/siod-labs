Описание
Рекурсивные функции и линейные структуры данных:
- `factorial` — факториал рекурсивно, O(n)
- `fib_naive` — числа Фибоначчи наивной рекурсией, O(φⁿ)
- `fib_memo` — числа Фибоначчи с мемоизацией, O(n)
- `hanoi` — Ханойские башни, 2ⁿ − 1 ходов
- `DynamicArray` — динамический массив с ручным управлением ёмкостью (рост ×2), амортизированная стоимость append = O(1)
- `Stack` — стек (LIFO) на базе DynamicArray
- `Deque` — дек на двусвязном списке, все операции концов O(1)

Сравнение с эталонными структурами (`list`, `collections.deque`):
- Вставка/удаление в начало: list — O(n), deque/Deque — O(1)
- Амортизированный анализ append методом учёта (банковским методом)
